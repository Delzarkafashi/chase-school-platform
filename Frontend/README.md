# Chase School Platform

Chase School Platform är ett projekt för att bygga en modern webbplats och lärplattform för Chase Yrkeshögskola.

Projektet kommer att bestå av två huvudsakliga delar:

- En publik webbplats där besökare kan läsa om Chase och utbildningarna.
- En lärplattform för elever, lärare och administratörer.
